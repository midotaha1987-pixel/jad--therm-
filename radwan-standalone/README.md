# معرض الرضوان — تطبيق إدارة المعرض (نسخة مستقلة)

تطبيق إدارة **معرض الرضوان للأدوات الصحية** (المحلة الكبرى — الشعبية، شارع حطين):
مخزون وفواتير ومديونيات ومشتريات وخزنة طوارئ ومصاريف وباقات وعمولات سباكين
ونقاط ولاء وتذكيرات وتقارير يومية — مع دفتر خاص للشيخ خالد البسيوني.

هذه النسخة المستقلة (Node.js + Express + SQLite) مطابقة لتطبيق Muse
(artifact `m-rd-lrdwn`) — نفس المستخدمين والمخازن والكتالوج (341 صنف) وقواعد التسعير.

## المستخدمون (كلمة المرور الافتراضية للجميع: `123456` — غيّروها بعد أول دخول)

| اسم المستخدم | الاسم | الدور |
|---|---|---|
| `rony` | روني | سوبر أدمن — يتحكم في المكونات الأساسية والصرف من الخزنة |
| `mohamed` | محمد عبد الرحيم | أدمن رئيسي |
| `hossam` | حسام أغا | مستخدم عادي |
| `khaled` | الشيخ خالد البسيوني | مستخدم عادي — صاحب المعرض |

> دفتر الشيخ خالد («أخد من مين / رجّع لمين» بالتواريخ) يراه هو وروني فقط —
> القيد مفروض على السيرفر، وليس في الواجهة فقط.

## قواعد التسعير (مطابقة للنسخة الحية)

- **آخر سعر شراء** يبدأ من سعر اللستة بعد خصم الشراء: البولي 20%، الأبيض 18%، الجوان 0%، لوازم عامة 0%.
- **سعر البيع التجاري** = آخر سعر شراء. **المميز** = اللستة × 0.82 (خصم 18%). **القطاعي** = اللستة × 0.88 (خصم 12%).
- كل الأسعار والنسب قابلة للتعديل من الإعدادات داخل التطبيق.
- كل تغيير سعر يُسجَّل في **سجل تغيير الأسعار** (قديم/جديد/التاريخ/مين غيّر).

## ما فيه التطبيق

- **المنتجات**: 341 صنف (187 بولي، 69 أبيض، 69 جوان، 16 لوازم عامة) تحت 3 ماركات
  (منتجات شركة جاد، منتجات شركة روكسي، نواكل) — 4 أسعار لكل صنف + الهامش،
  باركود لكل منتج (`RAD-0001`...) مع مسح بالكاميرا (BarcodeDetector) أو كتابة الرقم.
- **3 مخازن**: مخزن المعرض، المخزن الرئيسي، مخزن عام — المخزون لكل مخزن على حدة.
- **فواتير** حسب نوع العميل (تجاري/مميز/قطاعي)، تخصم من المخزون، تشحن حساب العميل،
  باقات بسعر موحد كسطر واحد، خصم كميات تلقائي، استبدال نقاط ولاء وكسب نقطة لكل جنيه.
- **مشتريات** تضيف للمخزون وتحدّث آخر سعر شراء، مع مديونية اختيارية للمورد.
- **مديونيات** حية مع كشوف حساب، وتحصيل/قيد.
- **دفتر الشيخ خالد** الخاص (مقفل إلا عليه وعلى روني) مع إدخال صوتي.
- **خزنة طوارئ**: تحويل تلقائي يومي من نقدية الفواتير (مبلغ ثابت أو نسبة — من الإعدادات)،
  والصرف بموافقة روني فقط مع شاشة تحذير، وتنبيه عند انخفاض الرصيد عن حد الأمان.
- **مصاريف** بتصنيفات وتسجيل فوري (كتابة أو صوت) وحد يومي وتقرير تحليلي.
- **باقات** بسعر موحد، **عمولة سباكين** بنسبة من الإعدادات مع تقرير مستحق/مدفوع،
  **نقاط ولاء** (نقطة لكل جنيه) تُستبدل بخصم.
- **تذكيرات**: عملاء غائبون ومديونيات قديمة (حد التأخير 30 يوماً افتراضياً) مع زر واتساب
  برسالة مهذبة جاهزة لكل شخص وسجل لمن تم تذكيره.
- **تقارير يومية**: نواقص المعرض (حد طلب افتراضي 5 + كمية مقترحة وتكلفة)، مديونيات يومية،
  ملخص صندوق يومي — كلها بمشاركة واتساب بضغطة واحدة (جروب المعرض + الشيخ خالد مباشرة).
- **بحث وأوامر صوتية** داخل التطبيق (Web Speech API — عربي مصري) مع **خطوة تأكيد**
  قبل تنفيذ أي أمر (مثلاً: «مصروف 50 جنيه إيجار» يعرض تأكيداً أولاً).
- **واتساب**: مشاركة الفواتير والتقارير والتذكيرات عبر روابط `wa.me` بنص جاهز.
- أرقام الواتساب لمحمد وحسام والشيخ خالد تُسجَّل من الإعدادات (فارغة افتراضياً).

> ملاحظة: فويس نوت الواتساب **لا يمكنه** تحديث التطبيق تلقائياً — الأوامر الصوتية
> داخل التطبيق هي الطريق (تسجيل صوتي من داخل التطبيق نفسه ثم تأكيد).

## التشغيل محلياً

```bash
cd radwan-standalone
npm install
node server.js
# ثم افتح http://localhost:3000 — دخول: rony / 123456
```

- قاعدة البيانات: `data/radwan.db` (تُنشأ تلقائياً مع كل البيانات الافتراضية).
  لتغيير مكانها: `DB_PATH=/path/to/radwan.db node server.js`.
- المنفذ: `PORT` (الافتراضي 3000).
- فحص الصحة: `GET /api/health` → `{"ok":true,"app":"al-radwan"}`.

## النشر على Railway (تسليم — خطوات روني/المسؤول)

التطبيق جاهز للنشر كخدمة جديدة من نفس الريبو — لا توجد خدمة Railway للرضوان بعد.

1. في Railway: **New Project → Deploy from GitHub repo** واختر الريبو
   `midotaha1987-pixel/jad--therm-`.
2. في إعدادات الخدمة: **Root Directory = `radwan-standalone`** (مهم — بدونها سيُنشر تطبيق جاد ثيرم).
3. أضف **Volume** جديداً واربطه على المسار `/app/data-vol`.
4. أضف متغير البيئة: `DB_PATH=/app/data-vol/radwan.db`.
5. انشر (Deploy) — الخدمة تبني من `Dockerfile` الموجود في `radwan-standalone/`.
   فحص الصحة: `https://<your-service>.up.railway.app/api/health`.
6. بعد ظهور الرابط الحي، حدّث `mobile/capacitor.config.json`:
   ضع الرابط الحقيقي مكان `https://radwan-placeholder.up.railway.app`،
   ثم نفّذ `npx cap sync android` وأعد بناء الـ APK/AAB
   (أو ادفع التغيير وسيبنيه GitHub Actions تلقائياً).

> تنبيه: بدون الـ Volume ستفقد البيانات عند كل إعادة نشر (نظام ملفات Railway مؤقت).
> لا تضع ملف قاعدة البيانات داخل الريبو.

## تطبيق أندرويد (APK / AAB)

- المشروع في `mobile/` — Capacitor 7.6.10، `appId: com.alradwan.app`، الاسم «معرض الرضوان».
- `server.url` في `mobile/capacitor.config.json` حالياً **PLACEHOLDER**:
  `https://radwan-placeholder.up.railway.app` — حدّثه بالرابط الحي بعد النشر على Railway.
- البناء محلياً:
  ```bash
  cd mobile
  npm ci
  cp ../public/index.html ../public/app.js ../public/style.css ../public/icon.svg www/
  cp ../public/icon-512.png ../public/icon-192.png ../public/manifest.json ../public/sw.js www/
  npx cap sync android
  cd android && ./gradlew assembleDebug   # APK
  ./gradlew bundleDebug                    # AAB (debug)
  ```
- البناء على GitHub Actions تلقائياً عند أي دفع يمس `radwan-standalone/**`:
  - `radwan-build-apk.yml` → ملف `app-debug.apk` (artifact: `al-radwan-apk`).
  - `radwan-build-aab.yml` → ملف AAB (artifact: `al-radwan-aab`)؛
    بدون أسرار التوقيع يُبنى `app-debug.aab` للتجربة فقط.
- لنشر Google Play لاحقاً: أنشئ keystore جديداً **خاصاً بالرضوان**
  (منفصل عن keystore جاد ثيرم) وأضف أسراره في GitHub
  (Settings → Secrets → Actions):
  `RADWAN_KEYSTORE_BASE64` و`RADWAN_KEY_ALIAS` و`RADWAN_KEY_STORE_PASSWORD`
  و`RADWAN_KEY_PASSWORD` — عندها يُبنى `app-release.aab` موقّعاً.

## ملاحظات تقنية

- **Service worker**: الكاش باسم `radwan-v1` في `public/sw.js`.
  **ارفع رقم النسخة عند كل تحديث لواجهة التطبيق** (مثلاً `radwan-v2`)،
  وإلا لن يرى المستخدمون المثبّتون التحديث (نفس الدرس من جاد ثيرم).
- **PWA**: زر تثبيت على شاشة الدخول + `manifest.json` (أخضر #14703D).
- الحسابات الافتراضية للتجربة (3 سباكين تجريبيين) معلّمة «قابلة للحذف» بانتظار
  شيت الإكسل بسباكين المعرض الحقيقيين.
- المخزون يبدأ صفراً في كل المخازن — أدخل الكميات الفعلية من المشتريات أولاً،
  وإلا سيعرض تقرير النواقص كل الأصناف.
- **لا أسرار ولا keystores في الريبو أبداً** — كلمة المرور الافتراضية `123456`
  نمط بذرة فقط، غيّروها بعد أول دخول من الإعدادات.
